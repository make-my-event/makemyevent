# Contributing to makemyevent

More detail coming soon. For now:
1. Fork + clone
2. `docker compose up -d`
3. `pnpm install && pnpm dev`
4. Branch off `development` and open your PR against `development`
   (the default, staging branch). `main` is production and only
   receives releases from `development`.

See [`docs/CONTRIBUTING.md`](docs/CONTRIBUTING.md) for the full guide.
